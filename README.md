# Hacker News Client

Клиентское веб-приложение для чтения новостей Hacker News, разработанное на React с использованием MobX и официального API Hacker News.

---

## 🛠 Стек технологий

- **Фреймворк:** [React](https://reactjs.org/) (v17/v18)
- **Управление состоянием:** [MobX](https://mobx.js.org/) & `mobx-react-lite`
- **Маршрутизация:** [React Router v5](https://v5.reactrouter.com/)
- **API:** Официальный [Hacker News Firebase API](https://github.com/HackerNews/API)
- **Пакетный менеджер:** [Yarn](https://yarnpkg.com/)

---
